# MarkdownIDE 项目文档

版本：V1.1 · 日期：2026-11-11 · 状态：开发前设计基线，待技术验证。

产品暂名“墨页”。目标是免费开源、本地优先、类 MarkText/Typora 的 Markdown 桌面编辑器，并通过文档 Agent 实现自然语言驱动的文档创建、读取、修改和删除。

## 已确定的设计方向

- Electron + Node.js + TypeScript；Vue 3 + Pinia + Vite；首版不建立独立云端后端。
- 首选评估复用 MarkText/Muya 编辑内核，经过中文输入法、往返保存及命令接口验证后确定复用范围。
- 主界面顶部菜单栏，下方左中右三栏：左侧元素/文件、中间编辑、右侧默认展开的目录。
- 即时渲染、源码和源码/预览分屏；左右侧栏可调宽和收起。
- AI 输入框位于编辑区底部中央，默认展开，可以向下收起；不覆盖正文。
- 文档 Agent 由本地应用实现，模型来自用户配置的本地、远程自建或模型厂商官方接口。
- 模型提交修改建议，应用负责文档定位、版本检查、差异展示、事务执行、保存和恢复。
- 增加 AI 预测：光标处续写、文稿结构和样式建议，接受后才进入文档事务；后台预测与显式 Agent 任务分开调度。
- 增加参考材料：图片、链接、引用文件分别指定为事实、数据、写作风格或视觉样式参考，并保留来源定位。

## 当前资产与实现状态

- UI 原型：[原型入口](../原型/index.html)、[六种状态总览](../原型/原型总览.html)、[原型说明](../原型/设计说明与使用指南.md)。
- 已有资产是 HTML/CSS/JS 交互原型及 PNG 截图，不是生产级 Electron 应用。
- AI 使用固定示例回复，Typora 导入只演示选择流程；原型不具备持续落盘和可靠 Markdown 往返。
- 本次交付为文档，不表示下文模块、协议、性能目标或模型接入已实现和实测。
- 不复用原型中的简化 Markdown 解析器、浏览器编辑命令或模拟保存逻辑作为正式编辑内核。
