## 布局说明

纵向以顶部全局工具栏 + 下方工作区为主体。全局栏高度 52px，放置品牌、文件/编辑/视图/帮助菜单、主题和导出入口。标签、编辑模式和格式动作位于中间编辑区自身的顶部，不新增全局功能区。

横向默认三分区：左侧 244px；中间自适应；右侧 238px。左右分界线均可拖动，左侧范围 190–330px，目录范围 170–370px。右侧默认展开，可收起，也可从中间底部状态栏恢复。

主编辑区为白色纸面，正文最大宽度 740px，适当留白而不采用卡片套卡片。默认文档标题 34px，正文 14px。目录突出当前章节，点击可定位。小屏时侧栏缩窄，推荐桌面宽度 1280px 以上；1100px 宽度已验证无页面横向溢出。原型最低布局宽度为 950px，不面向手机。

AI 输入框位于编辑区底部中央，宽度跟随编辑区。默认展开，顶部圆形下拉按钮向下收起；收起后保留单行入口，点击向上展开。AI 面板占据正常布局空间，正文区域随之调整高度，可独立滚动，不把输入框悬浮压在正文上。生成建议时面板自然增高，正文仍可滚动。AI 面板跨越源码与预览两列，不占用右侧目录。

## 可体验交互

1. 左上“元素 / 文件”切换。元素搜索即时筛选；文件搜索和示例文稿切换可用。
2. 基础元素可点击或拖入正文，在文末插入对应 Markdown；插入后可撤销。正式版应以实际光标或落点插入。
3. 三种模式：即时渲染、源码、分屏。源码输入会实时更新预览和目录；源码滚动按比例带动预览。
4. 目录点击定位，分界线拖动调宽，右上按钮收起，底部图标恢复。
5. AI 快捷指令、输入与 Enter 发送、Shift Enter 换行、Provider 类型选择、参考文档名称展示。
6. AI 采用固定模拟响应，明确标注“未连接模型”。点击“插入文档”后插入文末，点击撤销恢复。不会调用模型或发起网络请求。
7. 外观面板切换亮/暗/跟随系统；文稿样式切换衬线字体和留白宽度。Typora CSS 选择器展示导入反馈，不执行外来 CSS。
8. 打开本地 Markdown / TXT，导出当前 Markdown、HTML，调用浏览器打印/PDF。Word/EPUB 显示后续接入提示。
9. 专注模式隐藏左右侧栏，再次点击恢复。100% 缩放按钮在 100% / 110% / 90% 间循环。
10. 文件、编辑、视图、帮助菜单可展开；Escape 关闭菜单或主题弹窗。

## 应用外观与 Typora 文稿主题

两层设置分开：应用外观控制菜单、侧栏和 AI；文稿主题控制正文与预览。导入 Typora 主题后应先预览，再启用。正式实现需处理 #write 兼容层、本地资源、字体、公式/图表及导出样式，避免主题影响工具栏。

## 原型边界

这是 UI 与操作流程原型，不是已完成的生产编辑器。文稿与设置仅保存在当前页面内存，刷新会恢复示例；页面“已保存到本地”等状态是目标设计的视觉展示，并不代表后台持续落盘。需要保留编辑内容时使用导出。

源码编辑与预览可联动；即时渲染区支持浏览器内容编辑，但未实现完整 AST、选区映射和可靠 Markdown 往返，切换模式或重新渲染可能覆盖即时渲染区的临时输入。公式、Mermaid、图片路径、复杂 Markdown 方言采用结构示意，不提供生产级渲染。分屏采用比例滚动，尚无语义块级双向映射。

Typora CSS 导入只演示选择与反馈，不实际加载该 CSS。AI 不连接本地或远程模型；模型来源选择只演示三类 Provider。文件树为示例，不扫描磁盘目录。窗口控制、自动保存及高级格式转换需 Electron 与正式后端实现。SVG 图标及字体全部离线可用，无外部资源请求。
